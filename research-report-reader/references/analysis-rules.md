# 分析规则

在建立观点清单、分类和重组论证前阅读本文件。

## 分类

| 类别 | 实质研究对象 |
|---|---|
| 宏观 | 经济增长、通胀、就业、政策、国际收支与经济周期 |
| 行业 | 行业需求、供给、竞争、产业链、技术变迁与行业盈利 |
| 策略 | 大类资产配置、市场方向、风格轮动与投资组合策略 |
| 公司 | 单个或多个企业的经营、财务、估值与发展判断 |
| 固收 | 利率、信用、债券估值、偿付与固定收益策略 |
| 量化 | 因子、模型、统计检验、回测与系统化研究方法 |
| 基金 | 基金产品、经理、风格、业绩归因与基金配置 |
| 衍生品 | 期权、期货合约、波动率、基差、套保与结构化工具 |
| 大宗商品 | 商品供需、库存、价格及跨品种关系 |
| 其他 | 不适合上述类别但确属研报的研究；写明匿名研究主题 |

类别并列且去重。类别之间允许交叉，例如同时分析行业供需和商品价格可以标“行业、大宗商品”。只有实质讨论宏观机制才增加“宏观”，仅借用 GDP 假设不自动增加。封面自称的类别只是线索，以正文为准。

## 什么是一个观点

一个观点具有独立的研究含义：某项判断、可区分的研究回答、明确假设下的推演结论，或作者明确提出的风险判断。背景事实、每一个表格单元格、引入语和重复总结不必各自成为观点。

- 主观点包含多个实质不同的子结论时，应在输出中分别体现；同一主题下可以分段或分行，不必每条都再建一组固定栏目。
- 同一观点在摘要、正文和结论重复出现时合并，合并其新增证据和限定条件。
- 一个数字支持多个观点时可复用，不把数字本身重复拆成新观点。
- 单列的风险章节若提出实质新判断，应单独覆盖；纯免责声明不当作研究观点。
- 数字附录中的证据应接入有关观点；仅提供预测序列但无文字结论时，保留关键预测和口径，不凭数据自行发掘并添加新的结论。

内部清单建议记录：匿名主题、原文位置、内容类型、依据和条件、关联图表、重复项、读取缺口、拟输出位置。单纯观察可以映射到表格行，论证可以映射到段落。它是内部核对工具，不随笔记交付；不能用固定观点数代替覆盖审阅。

## 结构和语义的边界

- **研究重点**描述当前论点研究什么。收入预测的重点可以是“下一年的海外收入”，不必捏造“收入增长是否可持续”这一原文未讨论的问题，也不必把全篇研究范围重复到每节。
- **背景与假设**：已经发生的销量增长属于背景；作者设定未来销量不变才是关键假设。作者没有使用假设的描述性观察可以省略该栏目；不能自行补写回归误差独立等前提。
- **方法与假设**：选择样本、使用某数据库、按收入占比加权、比较同比增速，均属于依据与推导。若作者明确把未来需求增速设为某值，那一数值才是测算假设。判断依据是什么，与结论在什么条件下成立，要分开。
- **证据与结论**：先说明使用的数据、比较或计算，再交代得出的判断。观察、比较、测算或机制解释不自动构成实证检验；不为了填写栏目给原文添加验证环节。
- **模型与现实**：测算结果保留前提和预测期间。回测保留样本期、频率、比较基准及原文说明的成本口径，不代为运行新回测。
- **不适用、未披露与未读清**：行情记录没有假设通常是栏目不适用，直接省略；作者的测算缺少必要参数或关键步骤，才在对应位置简短说明；文件内容读不清是读取缺口，必须影响完成状态。

## 观察型内容如何归组

同一板块的市场行情、销售数据、价格指数等优先合并成段落或表格。共同日期或单位可放在表前，各行仍保留不同样本、期间或比较基准。列出的变化只来自原文，不能顺手扩展成预测或交易建议。

观察之后若有独立的原因解释或条件预测，另写一个分析段落。例如“成交下降”可以是一行数据，而“若补贴如期发放，需求可能改善”应保留其条件及依据。这样合并展示不等于合并不同观点。

## 重组与精度

同一主题可以汇集非相邻章节的背景、条件、依据和结论。只连结原文支持的关系，不创造作者未提出的总论点。保留不同模型、情景、样本或期间之间的区别。

对于数字，至少核对：数值、单位、期间、同比/环比、累计/单季、名义/实际、实绩/估计/预测、百分比/百分点。保留原文精度，不将不同口径误合并。原文中的概数仍保留“约”等限定。

对于图表，检查标题、轴单位、图例、样本范围和注释。仅在标签或正文明确给出数字时写精确值；不要从曲线位置反推精确值，也不要把这条操作说明附在每段末尾。无新增判断的图示作为相关主题的内部阅读依据；关键图表读不清时才在输出中说明缺口。不要把原图截图嵌入匿名笔记。

当同一指标出现不同值时，先检查期间、币种、口径或情景。确实未解释的差异要保留，在相应数据处说明一次即可，不必在假设、依据和结论中重复。关键计算衔接缺失也采用同一处理方式；不自行反推补齐，不开展外部查错。

## 长文完成条件

完成必须同时满足：每页已处理或判定为无实质内容；所有观点都有去向；关键图表已读或如实记录缺口；跨章节条件已合并；匿名映射与数字检查已完成。提取脚本成功本身不构成内容验收。

若尚有实质内容未读，输出状态只能是“整理中”或“部分完成”。不能把“本次只读了前几章”描述为覆盖全文。
